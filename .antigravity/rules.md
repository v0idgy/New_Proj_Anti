# Antigravity Global Workspace Rules
- **Stack:** Next.js (App Router), TypeScript (strict mode), Tailwind CSS, Lucide React icons.
- **Form Handling:** Zod for schema validation + React Hook Form.
- **Component Design:** Modular components under `src/components/`, pure utility functions under `src/lib/`.
- **Testing Rule:** Every UI mutation must be visually verified via the integrated browser agent before marking tasks complete.
